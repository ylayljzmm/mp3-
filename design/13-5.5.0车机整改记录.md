# 13 · 5.5.0 车机整改记录

车机（横屏 540 ~ 600dp 高）实测反馈收敛后，本轮只做「删与统一」六条，不新增功能。

## 1. 删沉浸态
8 秒无操作自动隐藏顶栏与功能行。车机上「控件自己消失」被用户判为失灵，
且需要一套触摸计时 + 淡出动画 + 隐式状态。→ `PlayerChromeController` 收敛为 `DUO` / `LYRICS_FULL` 两态，
`PlayerFragment` 删 `resetInteractionOnTouch()`（递归给整棵视图树挂 `OnTouchListener`）与 16 处 `onUserInteraction()`。

## 2. 删「仅封面」放大态
长按黑胶 800ms 放大到全屏封面。同上：隐式手势 + 一次状态跳变，车机上没有发现路径。
→ 删 `VinylRecordView` 的 `onTap` / `onLongPress` / `Handler` 计时器，只保留「圆盘内 `performClick`」。
**旋转四条约束逐条保留**：48 秒一圈、30fps 上限、暂停不清角度、封面反向等速。

## 3. 删设置页「歌词界面设置」入口
「用户界面」卡片里的这一行只是「展开高级歌词 + 平滑滚动到歌词卡片」，与下面「歌词」分组重复；
车机上点它会闪退。→ 删 `rowUiLyricsEntry` 整行、删点击绑定、删两个 string，
`cardLyrics` 上移为第 2 张卡（24 项歌词设置一项未减，折叠态与展开入口原样保留）。
副标题文案「配色、字体、字号与悬浮位置」迁到 `settings_advanced_lyrics_summary`，信息不丢。

## 4. 删顶栏队列按钮
功能行第 4 格已有同一入口，顶栏右侧留两个按钮在车机上挤。→ 删 `btnTopQueue`，
`onPlaylistChanged()` 只保留 `btnQueue.alpha` 的空队列置灰提示。

## 5. 功能行改纯图标
5 个文字标签（模式 / 收藏 / 音效 / 队列 / 信息）在 540dp 高的屏上只能拿到 14sp、还要占 16dp 行高。
→ 两份布局各删 5 个 `TextView`，无障碍描述改挂可点容器；行高 38/50/58/68 → 34/48/52/56，
省出的高度全部进进度带（8/10/10/10 → 22/24/26/28）与时间宽（32/38/38/38 → 40/46/46/46），
图标反而放大（16/22/22/22 → 22/28/30/32）。

## 6. 拼音排序口径
列表按 Unicode 排、索引轴按拼音分桶，两套口径不一致，点轴必跳错。
典型：`七` U+4E03 与 `万` U+4E07 码位只差 4，Q 段末尾紧邻 W 段开头；汉字整体在 ASCII 之后，
于是 A..Z 只能跳到英文歌。→ 新增 `model/LibrarySort.kt`（rank 主键 → Collator.SECONDARY → 裸字符串兜底弱序），
只改 4 处：专辑/艺术家分组序、歌曲页 `TITLE` / `TITLE_DESC`、专辑页索引跳过 `UNKNOWN`。
文件夹序、扫描序、艺术家列表、收藏、在线/电台/播客**一律不动**（无索引轴或非作品名）。

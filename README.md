# MP3播放器

比亚迪 DiLink 车机本地音乐播放器：**黑胶唱片播放页**、**卡拉 OK 逐字歌词**、**桌面 / 仪表屏悬浮歌词**、**方向盘 / 语音切歌**、**开机续播**。

当前版本：**v4.4.2**（versionCode 47）
下载地址：**https://github.com/ylayljzmm/mp3-/releases/latest**

> 一份安装包同时适配车机和普通安卓手机：横屏自动双栏，竖屏自动单栏。

---

## 功能一览

### 播放与列表

- 扫描 SD 卡 / 车机 `Music` 目录 / 自选文件夹中的 MP3、M4A、FLAC、WAV、OGG 等音频
- **播放列表缓存**：扫描结果自动保存，再次打开立即显示
- 底部三页导航：曲库 · 播放 · 设置（**打开 App 默认进入播放页**）
- 搜索、按歌手浏览、按歌名 / 时长排序；点进歌手后只播放该歌手歌曲
- **默认随机播放**，可切换顺序播放并记住选择（播放页左侧第一个按钮，只显示图标）
- 进度条拖动、当前时长 / 总时长显示
- **开机自动续播**（后台恢复，可选回到桌面，不强制打开界面）
- 双播放器冲突修复：切歌、方控、续播更稳定

### 歌词

- 自动匹配歌曲同目录的同名 `.lrc` 文件
- **联网歌词自动保存到歌曲旁边**（`歌曲名.mp3` → `歌曲名.lrc`），卸载 App 后歌词仍在
- 旧版 App 内部缓存的歌词，播放时会**自动迁移**到歌曲目录
- **多源歌词搜索**（国内优先）：网易云 → 酷狗 → QQ 音乐 → LrcLib
- **长按播放页歌词**可修改歌名 / 歌手并重新搜索
- 应用内滚动歌词 + 全局悬浮双行歌词 + **仪表屏滚动歌词**（需车机有副屏）
- 卡拉 OK：已唱字高亮，未唱字半透明
- **悬浮歌词配色**参考网易云：正在唱红色，未播放半透明白
- 歌词字体 8 种：系统默认、等宽、窄体、圆体、思源黑体、站酷快乐、马善政楷、思源宋体（部分字体首次使用需联网下载）
- 歌词配色 7 套：经典白、网易云红、淡粉、淡绿、淡蓝、薄荷、薰衣草
- 可调字号、**播放页歌词行距**、当前行放大、下一行缩小、平滑滚动、悬浮加粗等

### 封面与播放页

- **黑胶唱片**旋转封面（唱片与封面一起转），封面尽量占满右侧空间
- 播放页背景随专辑封面取色；底部导航与播放页色调融合
- 优先读取文件内嵌封面，无封面时可联网获取（iTunes）

### 横竖屏自适应

- **横屏（车机 / 平板）**：左栏黑胶 + 歌名歌手 + 播放控件，右栏整屏滚动歌词，同屏常显
- **竖屏（手机）**：单栏铺满；点黑胶唱片切换为整屏歌词，再点回到封面
- 旋转屏幕、分屏切换时自动重排布局，无需重启
- 底部预留可调的「车机 Dock 安全区」，避开系统任务栏

### 外观主题

- **驾驶配色**：夜航（暖琥珀）、林野（深绿金）、赛道（炭黑红）
- 三套方案均为低眩光深色界面，避免夜间驾驶时大面积亮底
- 歌词配色与应用主题相互独立

### 车机操控

- **方向盘媒体键**：优先由本 App 接管上一首 / 下一首 / 播放暂停
- **方控自愈**：后台持续确认媒体会话与按键路由，被车机组件抢走后自动重新接管
- **车内语音**：说「上一首」「下一首」等（需本 App 正在播放）
- 通知栏媒体控制；MediaSession 与音频焦点增强，减少误切到车机自带播放器

### 在线更新

- 更新源直接读取本仓库的 **GitHub Releases「最新正式版」**，发版即生效，无需额外服务器
- 下载走 **GitHub 资产 API**（`api.github.com` → `release-assets.githubusercontent.com`），
  避开国内常被拦截的 `github.com/.../releases/download` 域名；API 通道失败会自动回退直链再试
- 设置页点「检查更新」→ 发现新版本 → 下载 → 校验 SHA-256 与文件大小 → 拉起系统安装器
- 校验不通过不会安装，也不影响当前版本
- 所有版本使用**同一张固定签名证书**，因此后续版本可以直接覆盖升级
- 若车机网络访问不了 GitHub，可用手机或电脑打开上面的下载地址，拷贝到 U 盘安装

## 音乐与歌词放置

```
/sdcard/Music/
  ├── 歌手A/
  │   ├── 歌曲1.mp3
  │   └── 歌曲1.lrc      ← 可自己放，也可由 App 联网后自动创建
  └── 歌曲2.mp3
  └── 歌曲2.lrc
```

也可在 **设置 → 选择文件夹** 添加任意目录。

**没有本地 LRC 时：** 开启「联网获取歌词」，App 会自动搜索并**保存 `.lrc` 到歌曲同目录**。

**歌词不对时：** 在播放页 **长按歌词区域**，修改歌名 / 歌手后点「搜索」重新下载（会覆盖同目录 `.lrc`）。

## 安装到车机

1. 车机浏览器打开 `https://github.com/ylayljzmm/mp3-/releases/latest`，下载 `mp3-player-*-signed.apk`
   （或用电脑下载后拷到 U 盘，在车机上点开安装）
2. **首次安装 v4.4.2 请先卸载旧版**：v4.4.0 及更早的安装包是各自临时证书签名的，与本版证书不同，覆盖安装会提示「应用未安装」
3. 从 v4.4.2 起所有版本使用同一张固定证书，**以后可以直接覆盖升级，不用再卸载**

也可以用 adb：`adb install -r mp3-player-4.4.2-signed.apk`

## 车机必设权限（DiLink 4.0）

1. **存储权限**：允许读取（及写入）音频目录，以便保存 `.lrc`
2. **显示在其他应用上层**：悬浮歌词
3. **自启动 / 后台运行白名单**（极速模式）：防开机续播被杀
4. **安装未知应用**：应用内更新时要弹出安装器
5. 开启 **开机自动启动**、**启动时自动恢复播放**（按需）

## 使用步骤

1. **设置** 中添加扫描目录 → **扫描音乐**
2. 打开 App 即在 **播放页**；默认 **随机播放**
3. 车机横屏时封面与歌词同屏；手机上点黑胶唱片切歌词，手指上下滑可浏览整首歌词
4. **设置 → 歌词配色 / 字体 / 播放页歌词行距** 调整样式；**设置 → 驾驶配色** 换界面方案
5. 开启悬浮歌词 / 仪表屏歌词（仪表屏需车机支持副屏）

## 编译 APK

### GitHub Actions（推荐，不用装环境）

1. 推送到 `main`，或在 **Actions** 页手动运行 `Build APK`
2. 云端依次执行单元测试 + Release 构建（跳过 lint），再用仓库内固定证书 `signing/debug.p12` 签名
3. 构建完成后从 **Actions → 该次运行 → Artifacts** 下载 `MP3播放器-<版本>-已签名`
4. 解压得到 `mp3-player-<版本>-signed.apk`

> 早期版本曾改为每次构建现场生成证书，导致每次签名都不同、车机覆盖安装失败；现已改为仓库内固定证书，请勿删除 `signing/debug.p12`。

### Android Studio 本地编译

Release 未签名产物路径：`app/build/outputs/apk/release/app-release-unsigned.apk`
需要签名时用：`apksigner sign --ks signing/debug.p12 --ks-type PKCS12 --ks-key-alias androiddebugkey --ks-pass pass:android --key-pass pass:android --out 输出.apk app-release-unsigned.apk`
